# void Image Viewer
A lightweight image viewer for Windows with animated GIF/WEBP support.  
Opens and displays BMP, GIF, ICO, PNG, JPG, TIF and WEBP images as fast as possible.  
Animate GIF/WEBP files as accurately as possible.

Touch & Zoom Controls
--------
Touch gestures (pinch to zoom, two finger pan) on Windows 7+ touch hardware.
On-screen zoom controls: a zoom out / zoom in pill in the bottom right corner,
which grows to prev / play / pause / next / zoom controls in fullscreen mode.
Single finger input stays mouse compatible, so configured click actions are unaffected.
Toggle the controls from the View menu (Zoom Controls).
