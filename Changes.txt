Stable: Version 1.1.12 (the about title hard code fix round)

	the first round after the rollback is one hard code, the one the 1.1.11
	font round itself put on record ("the about title derives its larger
	face from it"): the derivation only ever covered the family. the
	height stayed the literal 32:
	- lf.lfheight = 32 was a 96 dpi design point. the message font scales
	  with the dialog window dpi (-18 at 150%, -24 at 200%) while the
	  title stayed 32 pixels on every screen: the 8/3 proportion the

	  site spells the w forms - the wide face name path hung on a
	  setting outside the code.

	  a dpi change between two about opens (a monitor reconfiguration,
	  a system scale move) kept drawing the stale face.
	the fix follows the font round's own derivation rule to the end:
	- the title derives from the live dialog font: wm_getfont on the
	  title control (the shared dialog proc applied the message font at
	  this dialog window own dpi before this case runs) -> getobjectw

	  -12 at 96 dpi and -12 * 8 / 3 = -32: the design point the

	  arrive with the font the dialog actually draws: one type system,
	  every dpi, both themes.
