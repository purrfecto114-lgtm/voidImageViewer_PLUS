Pre-release, BETA: Version 1.1.0-beta.8 (zoom input responsiveness, less GDI churn)
	zoom input got cheaper: the reachable top of the zoom ladder is now cached
	  behind an O(1) signature (its only inputs are the image, the viewport and
	  the layout settings), so a wheel tick or a window resize no longer
	  re-walks the 1024 entry ladder and no longer saves/restores the zoom
	  globals on every event.
	leaving 1:1 mode with the wheel now finds the re-entry zoom level with a
	  binary search (~10 render measurements instead of up to 1024): the old
	  linear scan called the full render-size computation once per ladder step,
	  which was measurable work right when the zoom started moving.
	paints no longer allocate and free a GDI brush each frame: the canvas
	  background brush is cached and rebuilt only when its color changes
	  (config or dark theme switch).
	no behavior change: the regression tests prove the binary searches return
	  exactly what the linear scans returned for every tested geometry, and the
	  ladder-top cache is validated against the measured value across
	  geometry-change sequences.

Pre-release, BETA: Version 1.1.0-beta.7 (zoom percent, 1600% zoom range, dark mode)
	the status bar zoom percent is fixed: it displayed garbage (a huge
	  negative number) because a double was passed where the printf read an
	  int. it now always shows the real zoom: rendered pixels / native pixels.
	  1:1 reads 100%.
	the zoom range is now honest and deep: the maximum is exactly 16x the
	  native size (1600%) for every image. previously the cap was 16x the
	  best fit size, which read as a weird 1590% for images that fit the
	  window and LOST deep zoom entirely for photos larger than the window
	  (a 4000px photo in a 1600px window topped out at 477%).
	zooming no longer has dead spots: the live top of the zoom ladder is
	  measured, so the wheel never spins through positions that all render
	  the same capped size, and the ladder stays clamped when the window
	  is resized.
	new: dark mode that follows the windows theme (windows 10 1809+): dark
	  title bar, dark menus, dark status bar and dark floating zoom
	  controls; the image canvas goes dark too unless you picked your own
	  color. choose automatic / light / dark in options -> general, and the
	  app follows the system light/dark toggle live without a restart.
	  older windows and high-contrast themes keep the light ui.
	  known limitations: the toolbar band and the options dialog contents
	  stay light (a dark icon set is future work), and the status bar size
	  grip is drawn by the system theme.
	every user-facing string for the new feature is localized (en/zh).
	a daily scheduled test run was added (github actions "tests" workflow):
	  the zoom math, menu structure and dark mode wiring regression suites
	  now run on every push and once a day.

Pre-release, BETA: Version 1.1.0-beta.6 (aspect ratio, zoom lag, menu cleanup)
	the image aspect ratio can no longer change while zooming: the pan && scan
	  feature that stretched the image independently in x and y (19 confusing
	  menu entries and 18 numpad shortcuts, including "increase width") has
	  been removed. the zoom ladder always scales both axes together.
	the status bar now shows a single zoom percent. (it used to show two
	  separate x/y percents, which read as if the aspect ratio could drift
	  while zooming.)
	zooming is no longer laggy at deep zoom: a magnified paint used to stretch
	  the entire destination rectangle (up to 16x the window = hundreds of
	  megapixels) even though only the visible part mattered. the stretch is
	  now limited to the visible area, so every zoom step repaints in
	  milliseconds instead of ~0.5s.
	regrouped the View menu: the ui toggles (caption, frame, menu bar, status
	  bar, toolbar, zoom controls, layout presets) now live in a Layout
	  submenu, leaving a short, scannable top level. the pan && scan submenu
	  is gone, fullscreen/slideshow/refresh sit together, and the zoom
	  commands stay in their own submenu.
	refreshed several chinese translations that were misleading: allow
	  shrinking now reads as shrinking the image (not the window), fill window
	  is labeled as stretching, the interpolation filter labels are less
	  technical, and the slideshow/slideshow-status strings are more natural.
	note: custom hotkeys saved for commands that moved into the View - Layout
	  submenu are reset to their defaults once (hotkeys are stored by menu
	  path). default hotkeys are unaffected.

Pre-release, BETA: Version 1.1.0-beta.5 (pinch zoom & zoom controls fixes)
	pinch to zoom now truly follows your fingers: the zoom tracks how far the
	  fingers moved, in or out. (the zoom steps were accidentally much larger
	  than intended on images larger than the window, so fast pinches overshot
	  wildly)
	corrupted gesture distances (reported with a monitor offset on some windows
	  builds) are now ignored, and no single gesture message can change the
	  zoom by more than 2x.
	pinch zooming now updates in one pass per gesture message instead of one
	  pass per 1% step, keeping fast pinches smooth.
	fixed the toolbar and floating zoom buttons: a single click used to zoom
	  all the way to the maximum or minimum. each click is now one visible
	  step (~10%).
	the floating zoom bar is now just two clear buttons, zoom out and zoom in,
	  drawn with the same icons as the toolbar. the 1:1, best fit and close
	  buttons were removed. (1:1, best fit and reset stay in the View - Zoom
	  menu and the right click menu; hide the bar from View - Zoom Controls)
	saving as JPEG now really uses quality 90. (the encoder parameter was
	  silently ignored before, windows saved at its default quality)
	the status bar no longer shows garbage for extreme aspect ratio images.

Pre-release, BETA: Version 1.1.0-beta.4 (quality of life)
	new in the File menu: Save As... saves the current image as PNG, JPEG or BMP. (Ctrl+S)
		re-encodes with the windows built-in GDI+ encoders, no new dependencies, no size cost.
		the in-memory rotation is included. alpha is flattened over the window background color.
		the typed extension (.png/.jpg/.jpeg/.bmp) picks the format, jpeg is saved at quality 90.
	new default navigation sort: by filename in natural order, ascending. (was: date modified, newest first)
		this matches windows explorer, so next/previous now walk the folder in the order you see it.
		existing installations keep their saved sort setting. change it from View - Navigation - Sort.
	the floating zoom controls bar now highlights the button under the cursor.
		hover repaints are limited to a single button. no image resources were added, keeping the executable small.

Pre-release, BETA: Version 1.1.0-beta.3 (smooth zoom & tearing fixes)
	zooming now uses fine 1% steps. (mouse wheel, toolbar buttons, pinch zoom and menu)
	fast wheel flicks zoom proportionally further in one event.
	pinch to zoom is much smoother, it follows the fingers with the same 1% granularity.
	the status bar now shows the real zoom level in percent, and it updates while zooming.
	fixed visible tearing and smearing while dragging images:
		the exposed area is now repainted immediately during the drag.
		all painting goes through a double buffer, every frame is presented in a single blit.
		scrolling no longer touches the status bar and toolbar area.
	added a close button to the floating zoom controls bar. (re-enable it from the View menu)
	reorganized the menus:
		all zoom commands now live in one View - Zoom submenu. (zoom in, zoom out, 1:1, best fit, reset)
		best fit is now visible in the menu. (it was hidden before)
		the right click menu now has a zoom section. (zoom in, zoom out, 1:1, best fit)
